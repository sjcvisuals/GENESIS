# GENESIS example scenes

Open from the editor: **File → Examples**.

| Scene | What it shows |
|-------|----------------|
| Particle Fountain | Cone emitter with bouncing sphere particles |
| Lava Fluid | Tall fluid volume + fluid-coupled particles |
| Animated Primitives | Cube / sphere / cylinder with looped keyframes |
| Imported FBX Animation | Stage + `assets/models/examples/spinning_cube.fbx` (Spin clip) |
| Audio-Reactive Lava | Same lava lamp; Examples menu wires bass/beat/onset → fluid |
| Medusa | Dual rings (~6 m rise + ~2 m floor) + one Wall Plane; single OSC person, wall-ray debug |

Also under `assets/scenes/`: **Room OSC Particles**, **Medusa**, **Tugela Soft Circles + OSC**.

Model assets for the FBX example live in `assets/models/examples/`.
