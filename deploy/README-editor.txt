Genesis Editor
==============

Single-monitor scene authoring tool (genesis_gltf_viewer.exe).

This is for creating and editing scenes. It does NOT model multi-GPU or
multi-output production canvases.

For playback / topology / PIXERA multi-output simulation, use tools under:
  GENESIS\Player\

Working directory for shortcuts must remain this Editor folder so shaders\
and assets\ resolve correctly.

Software updates
----------------
Help → Check for Updates… uses WinSparkle (WinSparkle.dll must sit next to
this exe). See docs/windows-auto-update.md for the appcast feed and signing.
